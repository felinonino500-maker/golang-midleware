Golang Middleware • Firebase RTDB + Firestore • Biar gampang dibaca di HP

📱 Termux 🐹 Go 🔥 Firebase 🛡️ Aman - Tanpa Key di Git

1 Pasang Project

Unduh dan jalankan installer. Script ini pasang Git + Go, clone repo ke $HOME/golang-midleware, lalu unduh module Go termasuk Firebase Admin SDK.

pkg install -y curl
curl -fsSL https://raw.githubusercontent.com/felinonino500-maker/golang-midleware/main/install-termux.sh -o install-termux.sh
chmod +x install-termux.sh
./install-termux.sh

2 Buat File Service Account Privat

⚠️ PENTING: Kunci lama yang pernah dibagikan harus dicabut di Google Cloud Console. Buat kunci pengganti setelah mencabutnya. Jangan kirim kunci ke chat, jangan masukkan ke Git, jangan taruh di folder project.

Buat direktori privat dan buka editor:

pkg install -y nano
mkdir -p "$HOME/.config/firebase"
chmod 700 "$HOME/.config/firebase"
umask 077
nano "$HOME/.config/firebase/service-account.json"

Tempel isi JSON service account pengganti langsung ke editor di perangkat Termux, lalu simpan Ctrl + O Enter dan keluar Ctrl + X. Setelah itu batasi izin file:

chmod 600 "$HOME/.config/firebase/service-account.json"
✅ Aturan emas: Jangan taruh JSON di golang-midleware/. .gitignore memang mengabaikan beberapa pola nama key, tapi simpan key di luar repo tetap lebih aman.

3 Atur Konfigurasi & Jalankan

Ganti AUTHORIZED_UIDS dengan UID pengguna dari Firebase Authentication yang boleh mengakses API:

export GOOGLE_APPLICATION_CREDENTIALS="$HOME/.config/firebase/service-account.json"
export FIREBASE_PROJECT_ID="bizflow-dashboard-vlo72"
export RTDB_DATABASE_URL="https://bizflow-dashboard-vlo72-default-rtdb.asia-southeast1.firebasedatabase.app"
export RTDB_PATH="firmware"
export AUTHORIZED_UIDS="firebase-auth-uid-anda"
export PORT="3000"

cd "$HOME/golang-midleware"
go run .

Jalankan perintah export lagi di sesi Termux baru. Untuk otomatis, tambahkan baris export tersebut ke ~/.bashrc (jangan taruh isi JSON key di dalamnya).

Buka di browser HP yang sama:

http://127.0.0.1:3000/

Halaman itu hanya cek koneksi RTDB dan Firestore. Halaman itu tidak menerima atau menyimpan service account.

🔒 Untuk akses dari perangkat lain, pakai IP perangkat Termux dan pastikan firewall / jaringan mengizinkan port tersebut. Jangan ekspos server ke internet tanpa HTTPS, pembatasan jaringan, dan pengamanan akses yang sesuai.
